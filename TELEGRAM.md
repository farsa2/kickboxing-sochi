# Отправка заявок в личку Telegram

Заявки с формы «Контакты» уходят в твой личный чат с ботом в Telegram.

## 1. Создать бота

1. Открой Telegram, найди **@BotFather**.
2. Отправь команду **/newbot**.
3. Введи имя бота (например: «Заявки Академия Кикбоксинг») и username (например: `academy_sochi_bot`).
4. Скопируй **токен** вида `123456789:AAH...` — это **TELEGRAM_BOT_TOKEN**.

## 2. Узнать свой chat_id (личка)

1. В Telegram найди своего бота по username и нажми **Start** или отправь любое сообщение (например **/start**).
2. В браузере открой (подставь свой токен):
   ```
   https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates
   ```
3. В ответе найди `"chat":{"id": 123456789}`. Число **123456789** — это твой **TELEGRAM_CHAT_ID**.

---

## Если сайт на GitHub Pages

На **GitHub Pages** работает только статический сайт, без сервера. Функция `api/send-telegram` там **не выполняется**. Чтобы форма отправляла заявки в Telegram, нужно:

### Вариант А: API на Vercel (рекомендуется)

1. Зарегистрируйся на [Vercel](https://vercel.com), подключи тот же GitHub-репозиторий.
2. В настройках проекта на Vercel добавь переменные:
   - **TELEGRAM_BOT_TOKEN** — токен из шага 1 выше.
   - **TELEGRAM_CHAT_ID** — твой chat_id из шага 2 выше.
3. Сделай деплой. Vercel выдаст URL сайта, например: `https://твой-проект.vercel.app`.
4. При сборке сайта для **GitHub Pages** укажи этот URL как адрес API. В репозитории создай файл **`.env.production`** (или настрой в GitHub Actions):
   ```
   VITE_TELEGRAM_API_URL=https://твой-проект.vercel.app
   ```
   Подставь свой URL с Vercel без слэша в конце.
5. Собирай и деплой на GitHub Pages как обычно. Форма будет отправлять заявки на `https://твой-проект.vercel.app/api/send-telegram`, а страницы — отдаваться с GitHub Pages.

Итого: **сайт** — с GitHub Pages, **отправка в Telegram** — через Vercel.

### Вариант Б: Всё на Vercel

Залить проект только на Vercel (без GitHub Pages). Тогда переменные **VITE_TELEGRAM_API_URL** не нужны: форма сама обращается на тот же домен (`/api/send-telegram`). В настройках Vercel достаточно задать **TELEGRAM_BOT_TOKEN** и **TELEGRAM_CHAT_ID**.

---

## Что дальше после настройки ключей на Vercel

1. **Проверь, что задеплоен тот же проект, где есть папка `api`.**  
   Если при открытии `https://твой-проект.vercel.app/api/send-telegram` в браузере появляется **404**, значит на Vercel залит репозиторий **без** папки `api` и файла `api/send-telegram.js`.  
   **Что сделать:** в настройках проекта на Vercel в разделе **Repository** привяжи репозиторий, в котором лежит этот сайт (с папкой `api` в корне). Затем нажми **Redeploy** (или сделай новый коммит и пуш в этот репозиторий).

2. **Переменные окружения уже заданы** (TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID) — после передеплоя они подхватятся.

3. **Проверка:** открой в браузере `https://твой-проект.vercel.app/api/send-telegram`. Ожидаемо увидишь не 404, а ответ вроде `{"ok":false,"error":"Method not allowed"}` — это нормально (метод GET не разрешён, форма шлёт POST). Значит эндпоинт работает.

4. **Сайт на GitHub Pages:** в репозитории создай файл **`.env.production`** в корне с одной строкой (подставь свой домен Vercel):
   ```
   VITE_TELEGRAM_API_URL=https://твой-проект.vercel.app
   ```
   Затем заново собери проект (`npm run build`) и залей на GitHub Pages. Форма будет отправлять заявки на этот URL.

5. **Сайт целиком на Vercel:** переменная **VITE_TELEGRAM_API_URL** не нужна. Достаточно задеплоить этот репозиторий на Vercel и задать TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID в настройках проекта.

---

## Локально (localhost)

Функция `/api/send-telegram` на компьютере не запускается. Отправка заработает после деплоя (GitHub Pages + Vercel для API или только Vercel).
